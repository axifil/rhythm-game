# Neon Rhythm

A polished, responsive rhythm game built with vanilla HTML, CSS, and JavaScript. Catch each note as it reaches the hit line, build your combo, and chase your personal best.

## Play

Open `index.html` in a modern browser. No build step or dependencies are required.

## Controls

- Press **A / S / K / L** or **← / ↓ / ↑ / →** to hit the matching lane.
- On touch screens, tap a lane.
- Press **Start game** to begin; press **Restart** at any time to start over.

Accurate hits award points and restore energy. Missed notes and off-beat presses break your combo and reduce energy. Your personal best is saved in your browser.

## Project files

- `index.html` — accessible game layout
- `style.css` — responsive visual design
- `script.js` — note timing, scoring, and game flow
